0Что подготовить (5 минут)

  • Чат-ИИ — любой: ChatGPT, Gemini, Claude. Лучше тот, где можно прикрепить картинку и получить длинный ответ.
  • Google-аккаунт — для stitch.withgoogle.com.
  • GitHub-аккаунт — github.com/signup.
  • Vercel-аккаунт — vercel.com/signup, входить через GitHub (так проще связать).
  • Ноутбук + один дешёвый Android для проверки.
Роли в команде: 1 человек ведёт чат-ИИ, 1 — Stitch, 1 — контент и вычитка таджикского, 1 — тестирует на телефоне.

1Определиться с идеей и тонкостями

Где: ChatGPT / Gemini / Claude · 15–20 минут

Не просите ИИ сразу «сделай сайт». Сначала пусть он задаст вам вопросы — так всплывут все тонкости: кто пользователь, какой телефон, какой язык, что опасно.

Промпт 1 — ИИ как наставник, выдаёт бриф
Ты — продуктовый наставник на хакатоне «Безопасность детей в интернете» в Таджикистане. Мы делаем простое веб-приложение (один HTML-файл, без сервера, без регистрации).

Наша тема: [вставьте кейс или идею одной фразой].

Задавай мне вопросы ПО ОДНОМУ (максимум 7), чтобы уточнить:
— кто пользователь (возраст, роль: ребёнок / подросток / родитель / учитель), какой у него телефон и интернет;
— какую одну проблему решаем и в какой момент человек откроет приложение;
— какие 3 экрана главного сценария;
— какие риски: что может напугать, пристыдить или навредить ребёнку;
— какие данные НЕ собираем (имя, фото, номер — не собираем никогда).

После ответов выдай БРИФ на одну страницу:
1) Пользователь. 2) Проблема одной фразой. 3) Главный сценарий: экран 1 → экран 2 → экран 3 (что на каждом). 4) Тон и стиль. 5) Что делаем в MVP и что НЕ делаем. 6) Куда ведёт кнопка «Мне нужна помощь». 7) Как поймём, что работает (1–2 проверки на людях).
Сохраните бриф в отдельный файл или заметку — он понадобится в шагах 2–4.

2Написать контент на двух языках

Где: тот же чат · 15 минут · контент — это 70% работы

Промпт 2 — контент в JSON
По нашему брифу напиши весь текст приложения на таджикском и русском.
Требования:
— простые короткие фразы, не больше 25 слов на карточку;
— без морали, без стыда, без пугающих слов; никогда не обвинять пострадавшего;
— только вымышленные ситуации и имена;
— таджикский — живой разговорный, буквы ӣ ӯ ҳ қ ҷ ғ.
Выдай результат одним JavaScript-объектом:
const content = { tj: { ... }, ru: { ... } }
с одинаковой структурой ключей для обоих языков (заголовки экранов, кнопки, карточки, тексты помощи).
Обязательно: таджикский текст должен прочитать носитель языка. ИИ ошибается в словах и окончаниях.

3Дизайн в Google Stitch

Где: stitch.withgoogle.com · 15–20 минут

  1. Войти через Google → New project → выбрать Mobile (наши пользователи — с телефона).
  2. Вставить промпт ниже. Stitch нарисует экраны.
  3. Поправить словами: «сделай кнопки крупнее», «цвета спокойнее», «добавь красную кнопку помощи внизу каждого экрана».
  4. Когда нравится — выбрать экран → иконка кода </> → скопировать или скачать HTML. Можно также Export → .zip. Плюс сделать скриншоты всех экранов.
Промпт 3 — для Stitch (пример под тему «Щит аккаунта»)
Mobile web app for teenagers 12–17 in Tajikistan: "Щит аккаунта / Сипари аккаунт" — protect your social media account in 5 minutes.

3 screens:
1) Home: big title, short subtitle, 3 large platform cards (Telegram, Instagram, TikTok) with icons, language switch "TJ | RU" top right.
2) Checklist for chosen platform: progress bar on top ("2 of 5"), 5 step cards (strong password, 2-step verification, who can message me, hide phone number, check active sessions). Each card: icon, short title, 1-line explanation, big "Done" toggle.
3) Result: shield illustration filling up, "Your account is protected", what to do if hacked (3 short steps), button "Check another app".

Fixed red button at the bottom of every screen: "Мне нужна помощь".
Style: modern, friendly, calm; deep teal + warm yellow accent on off-white; rounded cards, large tap targets (min 48px), large readable font, lots of white space. No photos of people. Cyrillic text.
Stitch часто лучше понимает английский промпт, а текст на экранах можно оставить русский/таджикский. Если результат слабый — прикрепите скриншот приложения, которое нравится, и напишите «в таком стиле».

4Собрать приложение — один index.html

Где: чат-ИИ · 15 минут

Даём ИИ три вещи: бриф (шаг 1), контент (шаг 2), дизайн (HTML из Stitch или скриншоты, шаг 3). Ниже — готовый промпт, на котором можно собрать приложение вживую.

Промпт 4 — сборка (живой пример «Щит аккаунта»)
Создай одностраничное веб-приложение в ОДНОМ HTML-файле на чистом HTML, CSS и JavaScript (без React, без фреймворков и npm — ничего не нужно устанавливать).

Название: «Сипари аккаунт / Щит аккаунта».
Пользователь: подростки 12–17 лет в Таджикистане, дешёвый Android, слабый интернет, таджикский и русский язык.
Проблема: аккаунты подростков взламывают и через них шантажируют или обманывают друзей, потому что никто не включил двухэтапную проверку и не настроил приватность.

Главный сценарий из 3 экранов:
1) «Что защищаем?» — 3 крупные карточки: Telegram, Instagram, TikTok.
2) Чек-лист из 5 шагов для выбранного приложения: надёжный пароль; двухэтапная проверка; кто может мне писать; скрыть номер телефона; проверить активные сеансы и выйти с чужих устройств. У каждого шага: заголовок, одно предложение «зачем», раскрывающаяся инструкция «где нажать» (3–4 коротких пункта), кнопка «Сделано». Сверху полоса прогресса «N из 5».
3) Итог: щит заполняется по числу выполненных шагов, фраза поддержки, блок «Если аккаунт уже взломали» (не плати и не отвечай шантажисту; сохрани скриншоты; восстанови доступ через «Забыли пароль»; предупреди друзей; расскажи взрослому), кнопка «Проверить другое приложение».

Кнопка «Мне нужна помощь / Ба ман кӯмак лозим» внизу на каждом экране, открывает окно с контактами (кнопки tel:):
102 — милиция; 1919 — телефон доверия МВД; 1313 — национальный телефон доверия.

Языки: таджикский (по умолчанию) и русский, переключатель «TJ | RU» вверху, выбор запоминается в localStorage.
Весь текст храни в одном JavaScript-объекте content = { tj: {...}, ru: {...} }.
Требования: мобильный экран от 360px, кнопки не меньше 48px, шрифт не меньше 16px, шрифт Noto Sans с поддержкой букв ӣ ӯ ҳ қ ҷ ғ (Google Fonts + системный запасной), без входа и регистрации, без сбора имени, фото и номера телефона, без внешних запросов кроме шрифта. Прогресс чек-листа храни только в памяти страницы.
Стиль: современный, дружелюбный, спокойный; глубокий бирюзовый + тёплый жёлтый на светлом фоне; скруглённые карточки. [Если есть — прикрепляю HTML/скриншоты из Stitch: повтори этот дизайн.]
Анимации: плавная смена экранов, появление карточек по очереди, щит заполняется, «Сделано» с лёгким отскоком. Только CSS (transition и @keyframes), 150–400 мс, только transform и opacity, без мигания; при prefers-reduced-motion анимации отключаются.

Выдай весь файл целиком одним блоком кода.
  1. Скопировать код из ответа → сохранить как index.html (в Блокноте/TextEdit: «Сохранить как», кодировка UTF-8, расширение .html).
  2. Открыть двойным щелчком в Chrome.
  3. Проверить как телефон: F12 → значок телефона (Toggle device toolbar) → ширина 360.
Если ответ обрезался — напишите «продолжи с того места, где остановился» или «выдай файл частями 1/3, 2/3, 3/3».

5Проверить и поправить

Где: чат-ИИ · по одной правке за раз

Правило: одна правка → сохранить → проверить. Не просите 10 изменений сразу.

Промпт 5 — примеры правок
Вот текущий index.html: [вставить код].
Исправь только одно: [кнопка «Сделано» не меняет прогресс / на экране 360px текст вылезает за край / язык не переключается на 2-м экране].
Ничего другого не меняй. Выдай файл целиком.
Промпт 6 — самопроверка от ИИ
Проверь этот index.html как строгий тестировщик: пройди весь сценарий на обоих языках, найди ошибки JavaScript, тексты без перевода, кнопки меньше 48px, места, где ребёнка могут напугать или пристыдить, и любой сбор личных данных. Дай список проблем, затем исправленный файл целиком.

6Залить на GitHub (без командной строки)

Где: github.com/new · 5 минут

  1. New repository → имя латиницей, например shield-account → Public → галочка Add a README → Create repository.
  2. В репозитории: Add file → Upload files → перетащить index.html (и позже manifest.json, sw.js, иконки).
  3. Внизу Commit changes.
  4. Чтобы обновить: снова Upload files с тем же именем файла → Commit. Старый файл заменится.
Никогда не загружайте на GitHub ключи API, пароли и личные данные — публичный репозиторий видят все.

7Опубликовать на Vercel (бесплатно)

Где: vercel.com/new · 3 минуты

  1. Войти в Vercel через GitHub (Continue with GitHub). План — Hobby (бесплатный).
  2. Add New… → Project → в списке репозиториев нажать Import напротив своего. Если репозитория нет — Adjust GitHub App Permissions и дать доступ.
  3. Framework Preset: Other. Build Command и Output Directory оставить пустыми.
  4. Deploy. Через ~30 секунд будет ссылка вида shield-account.vercel.app.
  5. Дальше всё автоматически: каждый новый Commit на GitHub = новая версия сайта через минуту.
Имя ссылки можно поменять: Project → Settings → Domains → изменить *.vercel.app.

8QR-код, офлайн-режим и финальная проверка

Перед пре-питчем 13 октября

  1. QR-код: в Chrome открыть свою ссылку → «Поделиться» → «QR-код». Распечатать или вставить в слайд.
  2. Офлайн (PWA) — промпт ниже, затем загрузить новые файлы на GitHub (шаг 6).
  3. Открыть ссылку на дешёвом Android при слабом интернете, затем в авиарежиме.
Промпт 7 — офлайн-режим
Сделай это приложение PWA: добавь manifest.json и service worker (sw.js), чтобы после первого открытия оно работало без интернета и устанавливалось на главный экран. Иконку сделай как inline SVG или дай мне простую SVG-иконку отдельным файлом. Покажи, какие строки добавить в index.html, и выдай manifest.json и sw.js целиком.
  • Открывается по ссылке и QR на дешёвом Android.
  • Главный сценарий проходится без подсказок.
  • Таджикский проверен носителем языка.
  • Нет входа, не собираются имя, фото, номер.
  • Кнопка помощи ведёт на проверенные номера.
  • Работает без интернета после первого открытия.
  • Протестировано на 2 людях из целевой группы.
